# Expense Tracker

A command-line expense tracker built in Python.

## What it does
- Add expenses with a name, category and amount
- Saves data to a file so it's remembered between sessions
- Shows totals and a spending report by category

## How to run it
1. Install Python 3
2. Download this project
3. In Terminal, run: `python3 tracker.py`
